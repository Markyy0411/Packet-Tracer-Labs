## 📂 Portfolio Structure & Lab Highlights

### 1️⃣ Routing and Protocols
*Complex routing topologies and dynamic protocol implementations.*
- **OSPF & EIGRP**: Single-Area OSPFv2, EIGRP Manual Summary Routes for IPv4/IPv6.
- **IP Addressing**: VLSM planning and comprehensive IPv6 configuration & static routing.
- **Resilience**: Floating Static Routes.

### 2️⃣ Switching and LANs
*Layer 2 technologies focusing on redundancy and performance.*
- **Redundancy Protocols**: Spanning Tree Protocol (STP), Rapid STP, and HSRP Synchronization.
- **Link Aggregation**: EtherChannel implementation.
- **Discovery**: CDP & LLDP configurations.

### 3️⃣ Network Security
*Securing the perimeter and internal network traffic.*
- **Traffic Filtering**: Comprehensive Standard and Extended IPv4 ACLs.
- **Layer 2 Security**: DHCP Snooping and Dynamic ARP Inspection.
- **Secure Communications**: GRE Tunnels and Site-to-Site VPNs.

### 4️⃣ CyberOps & Virtual Infrastructure
*A complete local VirtualBox infrastructure designed for threat hunting and penetration testing.*
- **Security Monitoring**: Dual-adapter Security Onion deployments.
- **Offensive Security**: Dedicated Kali Linux, Parrot OS, and BlackArch instances.
- **Vulnerable Targets**: Metasploitable2 and OWASP-BWA for safe exploitation practice.
- **Cisco NetAcad Environments**: DEVASC-LABVM and Cybersecurity LabVM Workstations.

### 5️⃣ Miscellaneous & Network Services
*Foundational services that keep the network functional and auditable.*
- **Services**: DHCPv4, DNS.
- **Logging & Time**: Syslog and NTP configurations.

## 🚀 Getting Started

To explore these labs on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Markyy0411/Packet-Tracer-Labs.git
   ```
2. **Prerequisites:** 
   - Cisco Packet Tracer (Version 8.0+ recommended).
   - VirtualBox (for replicating the CyberOps environment).
3. **Explore:** Open any `.pkt` or `.pka` file directly in Packet Tracer to interact with the topology and review device configurations.
