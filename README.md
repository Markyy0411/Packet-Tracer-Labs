Cisco Packet Tracer & Network Infrastructure Labs

Welcome to my repository of network administration and security laboratory exercises. This project serves as a comprehensive, hands-on documentation of my networking journey, focusing on routing, switching, and infrastructure security.

Repository Structure

This repository is divided into core networking domains, containing fully configured .pkt files, topology diagrams, and step-by-step documentation:

1_Routing_and_Protocols
Static routing, OSPF, EIGRP, and advanced routing protocol configurations.

2_Switching_and_LANs
VLANs, Trunking (802.1Q), Spanning Tree Protocol (STP), and EtherChannel.

3_Network_Security
Access Control Lists (ACLs), Port Security, VPNs, and device hardening.

4_CyberOps_and_Industrial
Advanced security operations, intrusion detection concepts, and industrial network topologies.

5_Miscellaneous_and_Basics
Foundational exercises, subnetting practice, and basic device configurations.

Getting Started

To explore or run these labs on your local machine:

Clone the repository:
git clone https://github.com/Markyy0411/Packet-Tracer-Labs.git

Ensure you have Cisco Packet Tracer installed (Version 8.0 or higher is recommended for full compatibility).

Open any .pkt file directly in Packet Tracer to view the topology and device configurations.
